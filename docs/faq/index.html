Installation & Setup

Is Internet Speed Monitor free to use?

Yes. Internet Speed Monitor is free and open source, released under the Unlicense. You can use, modify and distribute it without restrictions. There is no account and no paid tier.

Which operating systems does it support?

Windows 10 and later, macOS 10.15 and later (Apple Silicon and Intel), and Linux. Downloads: a Windows installer and portable zip, macOS .dmg files, and a Linux .deb plus .tar.gz.

How do I install Internet Speed Monitor on macOS?

Download the .dmg file for your Mac (arm64 for Apple Silicon, x64 for Intel) from our releases page, double-click it, and drag the app to your Applications folder. If you see a security warning, go to System Preferences > Security & Privacy and click "Open Anyway".

Why can't I open the app on macOS?

This is likely due to macOS Gatekeeper security. Right-click the app and select "Open", then click "Open" in the dialog. Alternatively, go to System Preferences > Security & Privacy > General and click "Open Anyway" after attempting to launch the app.

How do I install Internet Speed Monitor on Linux?

Download the .deb package and run sudo apt install ./internet-speed-monitor_*_amd64.deb. On other distributions, extract the .tar.gz and run the internet-speed-monitor binary.

Will I lose my history when upgrading from version 1.x?

No. Version 2 reads the same history and settings files. Installing it replaces 1.x: the macOS app is replaced in Applications, the Windows installer removes 1.x for you, and the Linux .deb upgrades the old package. A copy of your 1.x history is saved as speed_tests.backup-1.x.json before version 2 changes anything. If you used the 1.x AppImage or portable .exe, delete the old file yourself.

Usage & Features

Does monitoring continue when I close the window?

Yes. Closing the window leaves the app running in the system tray (the menu bar on macOS) and tests continue on your schedule. Click the tray icon, or launch the app again, to open the window. To start at login with only the tray icon, turn on "Start with computer" and "Auto-start monitoring" in the ☰ menu; the app offers both the first time it opens. See Running in the Background in the user manual.

How do I quit the app completely?

Choose Quit in the tray icon menu, or File → Quit in the window. The window's close button only closes the window. On Linux desktops that do not show tray icons (GNOME without the AppIndicator extension), launch the app again to get the window, then use File → Quit.

How accurate are the speed test results?

Internet Speed Monitor uses the same testing methodology as popular online speed tests. Results are typically within 5-10% of your actual connection speed. Factors like network congestion, server location, and other device usage can affect results.

What scheduling options are available?

The app offers two scheduling modes:

  • Simple Interval: Choose from preset buttons (5m, 15m, 30m, 1h, 1d) for regular testing
  • Cron Expression: Advanced scheduling using UNIX cron syntax for precise timing, including work hours presets and custom patterns

For most users, the Simple Interval presets are sufficient. Use Cron Expressions for complex schedules like "every weekday at 9 AM and 5 PM".

Where is my speed test data stored?

All data is stored locally on your device in JSON format. No data is sent to external servers. The data file locations vary by operating system:

  • macOS: ~/Library/Application Support/Internet Speed Monitor/speed_tests.json
  • Windows: %APPDATA%\Internet Speed Monitor\speed_tests.json
  • Linux: ~/.config/Internet Speed Monitor/speed_tests.json

How do I create custom cron expressions?

Cron expressions use five fields: minute hour day month weekday. Common examples:

  • 0 9 * * 1-5 - Every weekday at 9 AM
  • */30 9-17 * * 1-5 - Every 30 minutes during work hours
  • 0 */4 * * * - Every 4 hours
  • 0 0 * * 0 - Every Sunday at midnight

Use the "Help with cron expressions" link in the app to access crontab.guru for interactive help building expressions.

Can I export my speed test data?

Yes! Click the "Export CSV" button to save all your speed test data to a CSV file. This includes timestamps, download speeds, upload speeds, and ping times. You can then open this file in Excel, Google Sheets, or any spreadsheet application.

How much bandwidth does continuous monitoring use?

Each speed test uses approximately 10-50 MB depending on your connection speed. With a 15-minute interval, this equals roughly 2-10 GB per month. You can adjust the interval to control bandwidth usage.

Troubleshooting

The app won't start or crashes on startup

Try these steps:

  1. Restart your computer
  2. Make sure you have the latest version installed
  3. Check if antivirus software is blocking the app
  4. On Windows, try running as administrator
  5. If the issue persists, create an issue on our GitHub page with details about your system

Speed tests are failing or showing "Connection Error"

This usually indicates a network connectivity issue:

  • Check your internet connection
  • Verify firewall settings aren't blocking the app
  • Try temporarily disabling VPN if you're using one
  • Restart your router/modem
  • Contact your ISP if problems persist

The chart isn't updating or shows no data

Ensure monitoring is running by checking that the "Start Monitoring" button shows "Running" status. If monitoring is active but no data appears, try:

  • Stopping and restarting monitoring
  • Restarting the application
  • Checking if your firewall is blocking network requests

Privacy & Security

What data does the app collect?

Internet Speed Monitor only collects speed test measurements (download speed, upload speed, ping, timestamp). No personal information, browsing data, or other private information is collected. All data stays on your device.

Is my data shared with third parties?

No. All speed test data is stored locally on your device. The app does not send any data to external servers or third parties. We respect your privacy completely.

Can I delete my stored data?

Yes. You can clear all stored data by deleting the application's data folder (see "Where is my data stored?" above) or by uninstalling and reinstalling the application.
